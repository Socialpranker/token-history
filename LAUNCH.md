## Сегодня (день 0) — 15 минут
1. Создать репо `token-history` на GitHub (public), запушить эту папку.
2. Найти-заменить `REPLACE_GH_USER` → свой ник (README.md, index.html, collect.mjs — UA).
3. Settings → Pages → Source: Deploy from branch → `main` / root.
4. Actions → collect → **Run workflow** (первый снапшот). Проверить: появились `data/apps/<сегодня>.json`, `data/index.json`, бейджи; в логе `stars=N/7`; сайт открывается, demo-баннер исчез.

6. Глянуть repos.json: 3 маппинга проверены (openclaw, hermes-agent, roo-code), 4 — общеизвестные (cline, sillytavern, open-webui, openhands); если какой-то даёт 404 в логе — поправить или удалить, это не ломает ран.

**Каждый день без сбора = дыра в архиве навсегда. Сначала запустить, потом полировать.**

## Запуск на HN (день ~14+)
- Окно: **12:00–17:00 UTC**, день недели не важен (день недели статистически незначим, p=0.81 — arXiv 2511.04453). «Show HN» преимущества не даёт — можно без него.
- **Центральный фрейм: «все метрики агентов — храповики, эта — единственная умеет падать».** Звёзды/downloads не убывают → мёртвый проект неотличим от живого; токены оплачиваются еженедельно → кривая честная. Иконическая картинка (к v1.1): OpenClaw — звёзды растут, токены падают, один график.
- Заголовок-кандидаты (проблема, не продукт):
  - "The first AI-agent leaderboard where lines can go down"
  - "Stars can be faked for $0.10. Token usage can't. I archive the AI-agent usage leaderboard daily"
  - "Hermes passed OpenClaw with half the stars — nobody noticed. Now there's a chart"
- Первый комментарий (свой): методология + bias-дисклеймер + «архив — это репо, форкается одной кнопкой» + аргумент «звёзды восстановимы задним числом через API, токены — нет, поэтому архив должен был начаться вчера». Честность про ограничения = главный щит от топ-комментария «but this only sees OpenRouter traffic».
- После HN: r/LocalLLaMA, X-тред с кривой Hermes/OpenClaw, lobste.rs.
