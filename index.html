Hype gap — stars per billion daily tokens

Stars are cumulative attention; tokens are today's paid usage. High ratio = loud relative to current usage, low ratio = workhorse. Only apps mapped to a GitHub repo in repos.json appear here.

Depth — tokens per request

Rough session-depth proxy: agentic tools burn tens of thousands of tokens per request, chat-style apps far fewer. Computed from the same snapshot.

Methodology. Charts show the daily token window from OpenRouter's app rankings, snapshotted twice a day (week and month windows are archived in each snapshot too; alerts use the stabler week window). Token counts come from each provider's own tokenizer and are not strictly comparable across providers.

Bias. Only traffic routed through OpenRouter is visible. Apps that talk to providers directly (e.g. subscription products) are undercounted. Treat this as a relative trend signal, not absolute adoption.
